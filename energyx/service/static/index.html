Getting a good answer

  • Ask complete, self-contained questions — each one is answered on its own terms.
  • Name what you want: a building, a city, a period, a measure.
  • Questions are answered one at a time, so an answer may take a moment to arrive.

The system works from electricity data for 2016–2017 and says so clearly whenever a question falls outside what the dataset holds.

Using this interface

A short guide to the controls, so nothing here has to be discovered by trial.

Asking

Question list

The 50 evaluation questions, on the left. Select one and it is asked immediately. Filter by category, level or text.

Run all

Asks every question currently shown, one after another. Press it again to stop.

Tick / cross

Appears beside a question once answered. It is the evaluation grader's verdict, the same one that produced the reported figures — not a self-assessment.

Controls

Planner

Which model plans the analysis. The larger model takes longer to load the first time you switch to it.

Check

Shows what the system understood — entities, period, measure — before it runs anything. Correct a reading here and ask with your correction.

Browse

Walks the catalogue: countries, cities, sites, buildings. Useful for finding a building name to ask about.

Electricity is the only metered channel, with site weather and building metadata alongside it; a question outside that, or outside 2016–2017, is answered by saying what is missing.
